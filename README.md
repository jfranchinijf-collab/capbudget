# Cap Budget

Votre budget, clair et net. Le tableau de bord des petites entreprises et des particuliers.

Importez votre relevé bancaire (CSV, PDF ou capture d'écran) : Cap Budget classe les opérations, crée les catégories et affiche dépenses et revenus mois par mois.

Les données restent dans le navigateur de l'utilisateur : rien n'est envoyé sur un serveur.
